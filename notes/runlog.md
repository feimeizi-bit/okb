# runlog.md — 跑批日志

> 中文名：实验记录
> 用途：每次跑批后追加一条记录（约 2 分钟）。
> 双重作用：既是我们自己查问题的依据，也是赛题"支持批量运行和结果追踪"这条评分要求的**直接交付物**。

---

## 记录模板（复制下面这段追加到文件末尾）

```
## <run_id> · <日期>
- 目的：这次想验证什么（一句话）
- 配置：agent= · suite=<数据集版本> · judge=<判官版本> · 重复次数=
- 结论：数字 + 一句话判断（例如"A=0.91 / B=0.62 / C=0.24，六维单调可分"）
- 异常：无 / 具体是什么
- 产物：runs/<run_id>/report/summary.md
```

## 写日志的三条规矩

1. **结论里必须带数字**，不能只写"效果不错"
2. **异常必须写**（哪怕最后解决了也写，解决方式也写）—— 这是"稳定性"的证据材料
3. **产物路径必须写全** —— 三周后你不会记得东西放在哪

---

## 与 claims.md 的关系

`runlog` 是原始记录，`claims.md` 是可对外说的话。
当某条 runlog 的数字足以支撑 claims.md 里的某句话时，去 claims.md 把那一行的状态改成 `已取得`，并把 run_id 填进「证据落点」栏。
